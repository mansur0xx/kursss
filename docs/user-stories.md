# User stories (5-сабақ)

Пішім: «[рөл] ретінде мен [әрекет] қалаймын, себебі [пайда]»  
MoSCoW: **M** - міндетті, **S** - керек, **C** - болса жақсы, **W** - бұл нұсқада жоқ

---

## User Stories кестесі

| ID | Story | M/S/C/W | Шарт |
| :--- | :--- | :---: | :--- |
| **US-1** | Мұғалім ретінде мен тест құрып, сұрақтар мен нұсқалар қосқым келеді, себебі студенттердің білімін стандартты түрде бағалау қажет | **M** | Әр сұрақта 4–5 нұсқа; дұрыс жауап белгіленбесе → 422; таймер 5–60 минут |
| **US-2** | Мұғалім ретінде мен дайын тестті жариялағым келеді, себебі студенттер тек толық тексерілген тестті тапсыра алуы тиіс | **M** | Сұрақсыз бос тест жарияланбайды → 400; жарияланған соң ғана студенттерге көрінеді |
| **US-3** | Мұғалім ретінде мен тақырып бойынша AI-дан сұрақтарды автоматты дайындап алғым келеді, себебі сұрақ құрастыру уақытын үнемдеймін | **M** | Тақырып енгізгенде 5 сұрақ дайындалады; AI істемесе → fallback шаблоны шығады |
| **US-4** | Студент ретінде мен тест тапсырып, ұпайымды бірден көргім келеді, себебі өз нәтижемді жылдам білу маңызды | **M** | Тест аяқталған соң балл бірден есептеледі; тестілеу кезінде дұрыс жауаптар көрінбейді |
| **US-5** | Студент ретінде мен кері санақ таймерін көріп отырғым келеді, себебі уақытымды дұрыс жоспарлап үлгеруім қажет | **S** | Таймер 0-ге жеткенде тест автоматты тоқтап, белгіленген жауаптар сақталады |
| **US-6** | Студент ретінде мен басқа вкладкаға ауысқанда ескерту алғым келеді, себебі көшіру тәртібін бұзбауым керек | **S** | Басқа терезеге өткенде сары ескерту шығады, бірақ балл шегерілмейді |
| **US-7** | Студент ретінде мен бұрын тапсырған тесттерімнің тарихын көргім келеді, себебі өзімнің білім прогресімді бақылаймын | **S** | Студент тек өзінің нәтижелерін көреді, өзгелердің жеке бағалары көрінбейді |

---

**MVP шегі:** US-1 – US-4 (Барлық Must санатындағы 4 негізгі story)
